## :computer:How to use

### Locally

1. Clone this repository

```bash
git clone https://github.com/siosond/remove-bg.git
cd remove-bg
```

2. Install dependencies (Node.js >= 22.12)

```bash
npm install
```

3. Start web-application

```bash
npm run dev
```
